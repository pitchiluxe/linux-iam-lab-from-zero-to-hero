Most IAM work on Linux happens in a **terminal**: a text window where you type a command, press Enter and read the answer. This module makes you comfortable there.

## Two places you can type

> **Windows** The Windows PowerShell prompt looks like `PS C:\Users\you>`. You use it only to start, stop and reset the lab, or to connect with `ssh linux-iam-lab`. Linux commands such as `ls -l /etc` will not work there.

The Linux prompt looks like this:

```text
student@iamlab01:~$
```

| Part | Meaning |
|---|---|
| `student` | the account you are logged in as |
| `iamlab01` | the computer (host) you are on: the lab VM |
| `~` | your current folder; `~` is short for your home folder `/home/student` |
| `$` | you are a normal user. Root, the all-powerful admin account, sees `#` instead |

## Anatomy of a command

```linux
ls -l /etc/passwd
```

- `ls` is the **command** (list files).
- `-l` is an **option** (also called a flag): long format. Options change how a command behaves. Short options use one dash (`-l`); long options use two (`--all`). Short options can be combined: `ls -la` is `ls -l -a`.
- `/etc/passwd` is an **argument**: what the command works on.

```text
-rw-r--r-- 1 root root 2401 Nov 11 09:12 /etc/passwd
```

Linux is **case-sensitive**: `ls` works, `LS` does not; `Report.txt` and `report.txt` are different files.

## Paths

- An **absolute path** starts at the root folder `/`, for example `/home/student/lab`.
- A **relative path** starts where you are: in `/home/student`, `lab/m01` means `/home/student/lab/m01`.
- `.` is the current folder, `..` the parent folder, `~` your home folder.

## Core file commands

| Command | Does | Example |
|---|---|---|
| `cd DIR` | change directory | `cd /etc`, `cd ..`, `cd ~`, `cd -` (previous folder) |
| `ls` | list | `ls -la` (long, include hidden files that start with `.`) |
| `mkdir -p` | make folders (and parents) | `mkdir -p ~/lab/m01/tickets` |
| `cp` | copy | `cp file copy.txt`, `cp -r dir1 dir2` (folders need `-r`) |
| `mv` | move or rename | `mv old.txt new.txt`, `mv a.txt dir/` |
| `rm` | delete files | `rm -i file` (ask first); `rm -r dir` deletes a folder tree |
| `rmdir` | delete an **empty** folder | `rmdir ~/lab/old` |
| `cat` / `less` | show a file / page through it | `less /etc/passwd` (`q` quits, `/word` searches) |
| `nano` | edit text | `Ctrl+O` save, `Ctrl+X` exit |

## Keys that save you time

| Keys | What they do |
|---|---|
| `Tab` | complete a command or file name; press twice to list choices |
| `Up` / `Down` | walk through previous commands |
| `Ctrl+R` | search history: type part of an old command; `Ctrl+R` again for older matches; `Enter` runs it, `Esc` lets you edit it |
| `Ctrl+C` | cancel the running command: your "get me out of here" key |
| `Ctrl+D` | end input, or log out of a shell |
| `Ctrl+L` | clear the screen |
| `Ctrl+A` / `Ctrl+E` | jump to start / end of the line |
| `Ctrl+U` / `Ctrl+W` | delete to start of line / delete previous word |
| `q` | quit `less` and `man` |

`history` lists what you typed; `!42` re-runs entry 42 (read it first!).

## Getting help

- `man ls` opens the manual page. Inside: `/pattern` searches, `n` next match, `q` quits.
- Manual **sections** matter: `man 1 passwd` is the command, `man 5 passwd` is the **file format** of `/etc/passwd`.
- `ls --help` prints a short summary. `type cd` tells you whether something is a builtin, alias or program. `man -k keyword` searches all page titles.

## Recovering from common mistakes

- **No prompt comes back**: the command is waiting for input (for example `cat` with no file). Press `Ctrl+C`.
- **`command not found`**: check spelling and case; `sl` is not `ls`.
- **`No such file or directory`**: check where you are with `pwd` and `ls`; use Tab so you cannot misspell.
- **A `>` prompt appears**: you opened a quote and did not close it. `Ctrl+C` and retype.
- **Stuck in `vim`**: press `Esc`, type `:q!`, Enter. This course uses `nano`.
- **File name with spaces**: quote it: `cat "my report.txt"` or escape the space: `cat my\ report.txt`.
- **File name starting with a dash**: `rm -- -notes.txt` or `rm ./-notes.txt` (`--` means "no more options").
- **`Permission denied`**: you are not allowed to do that as `student`. That is often *correct*; later modules teach when `sudo` is appropriate.

> **Careful** `rm` deletes immediately - there is no Recycle Bin on Linux. Use `rm -i` while learning.
