Profile text, posts and Projects entries for sharing the Linux IAM lab. Fill every `[BRACKET]`, change the wording so it sounds like you, then post.

## Homework checklist

- [ ] Headline that says what you do (`00`)
- [ ] About: three sentences, what you built, what you can do, the role you want (`00`)
- [ ] Feature the capstone repository and its test report (`00` → Featured)
- [ ] One Projects entry: onboard, troubleshoot, revoke and evidence a contractor (`06`, first entry)
- [ ] Skills: Linux, Bash, sudo, OpenSSH, PAM, SSSD, LDAP, auditd, access reviews, least privilege (`00`)
- [ ] Post once: a screenshot of an allowed and a denied test, and the one thing it taught you (`04`)
- [ ] Next: book LFCS or CompTIA Linux+ (`05`)

## Posting tips

- **One post every 5–7 days.** Steady beats a burst.
- **Tuesday–Thursday, 8–10 am** your time gets the most reach.
- **Put the GitHub link in the first comment**, not in the post: LinkedIn shows posts with outside links to fewer people.
- **One image** per post: a cropped screenshot is enough.
- **Reply to every comment in the first hour.**
- 3–5 hashtags, at the end.
- Before posting a screenshot: no Windows username, browser tabs, portal token in the address bar, or real hostnames.
